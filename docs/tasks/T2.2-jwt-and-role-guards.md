# T2.2 — JWT Guard і Role Guard

**Епік:** 2. Автентифікація | **Залежності:** T2.1 | **Оцінка:** S

## Мета
Захистити API та розмежувати права.

## Що зробити
- [ ] `JwtAuthGuard` (Passport JWT strategy), глобально або на контролерах
- [ ] Декоратор `@Public()` для відкритих ендпоінтів (`/auth/*`, `/health`)
- [ ] Декоратор `@Roles('agent')` + `RolesGuard`
- [ ] Декоратор `@CurrentUser()`
- [ ] Правило: `agent` бачить усі тікети, `user` — лише свої

## Acceptance criteria
- Запит без токена → 401
- `user` на чужий тікет → 403 (або 404)
- `agent` має доступ до всіх тікетів
- Покриття правил описане в README (таблиця ролей)
