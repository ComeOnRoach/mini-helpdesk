# T5.2 — Фронт: real-time тости та бейдж

**Епік:** 5. Real-time | **Залежності:** T5.1, T3.4 | **Оцінка:** M

## Мета
Показувати зміни без перезавантаження сторінки.

## Що зробити
- [ ] WebSocket-клієнт (`socket.io-client`), підключення після логіну, відключення при logout
- [ ] Toast «Новий коментар у тікеті #N» з посиланням
- [ ] Бейдж лічильника непрочитаних у хедері
- [ ] Автооновлення коментарів на відкритій сторінці тікета
- [ ] Індикатор стану з'єднання (online/reconnecting)

## Acceptance criteria
- Коментар, доданий в іншій вкладці, з'являється без reload
- Бейдж скидається при відкритті тікета
- Втрата з'єднання не ламає UI

## Playwright-тема
Два контексти/користувачі одночасно, очікування WebSocket-подій.
