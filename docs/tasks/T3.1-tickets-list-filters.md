# T3.1 — GET /tickets: пагінація, фільтри, пошук

**Епік:** 3. CRUD тікетів | **Залежності:** T2.2 | **Оцінка:** M

## Мета
Список тікетів із гнучкою вибіркою.

## Що зробити
- [ ] `GET /tickets?page=1&limit=10&status=open&priority=high&tag=bug&q=text&sort=createdAt:desc`
- [ ] Відповідь: `{ items: [], total, page, limit }`
- [ ] Пошук `q` по title та description (LIKE)
- [ ] Валідація query-параметрів через DTO
- [ ] Обмеження `limit` ≤ 50
- [ ] Врахувати ролі: `user` — лише свої

## Acceptance criteria
- Фільтри комбінуються
- Порожній результат → `items: []`, `total: 0`
- Сортування за замовчуванням: новіші першими
- Описано в Swagger
