# T3.1 — GET /tickets: пагінація, фільтри, пошук

**Епік:** 3. CRUD тікетів | **Залежності:** T2.2 | **Оцінка:** M

## Мета
Список тікетів із гнучкою вибіркою.

## Що зробити
- [x] `GET /tickets?page=1&limit=10&status=open&priority=high&tag=bug&q=text&sort=createdAt:desc`
- [x] Відповідь: `{ items: [], total, page, limit }`
- [x] Пошук `q` по title та description (LIKE)
- [x] Валідація query-параметрів через DTO
- [x] Обмеження `limit` ≤ 50
- [x] Врахувати ролі: `user` — лише свої

## Acceptance criteria
- Фільтри комбінуються
- Порожній результат → `items: []`, `total: 0`
- Сортування за замовчуванням: новіші першими
- Описано в Swagger
