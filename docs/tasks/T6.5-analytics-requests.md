# T6.5 — Аналітика: запити для перехоплення

**Епік:** 6. Складні UI-сценарії | **Залежності:** T3.4 | **Оцінка:** S

## Мета
Мати «зайві» мережеві запити, які можна блокувати та перехоплювати.

## Що зробити
- [ ] Ендпоінт `POST /analytics/events` (приймає `{ event, page, ts }`, повертає 204; можна нічого не зберігати)
- [ ] Фронт-сервіс `track(event)`: логін, створення тікета, відкриття тікета, пошук, експорт
- [ ] Запити йдуть на `/analytics/**`, помилка аналітики не ламає UI
- [ ] Увімкнення/вимкнення через `VITE_ANALYTICS_ENABLED`

## Acceptance criteria
- Кожна ключова дія створює запит до `/analytics/events`
- При блокуванні запиту застосунок працює як раніше

## Playwright-тема
`page.route('**/analytics/**', route => route.abort())`, перевірка кількості та payload запитів.
