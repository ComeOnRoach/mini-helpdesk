# T2.1 — Реєстрація та логін (JWT)

**Епік:** 2. Автентифікація | **Залежності:** T1.2 | **Оцінка:** M

## Мета
Дати користувачам змогу реєструватись і отримувати токен.

## Що зробити
- [ ] `AuthModule`, `AuthService`, `AuthController`
- [ ] `POST /auth/register` (email, password) → створює user з роллю `user`
- [ ] `POST /auth/login` → `{ accessToken, user }`
- [ ] Хешування паролів через `bcrypt`
- [ ] JWT (`@nestjs/jwt`), термін життя з env
- [ ] `GET /auth/me` — поточний користувач

## Acceptance criteria
- Реєстрація з існуючим email → 409
- Невірний пароль → 401
- Пароль ніколи не повертається у відповідях
- Ендпоінти описані в Swagger

## Нотатки
Це база для UI-тестів логіну (позитивні/негативні сценарії).
