# T4.3 — Експорт тікетів у CSV

**Епік:** 4. Файли | **Залежності:** T3.1 | **Оцінка:** S

## Мета
Експортувати відфільтрований список тікетів.

## Що зробити
- [x] `GET /tickets/export?status=...&priority=...` → `text/csv`, `Content-Disposition: attachment; filename="tickets-YYYY-MM-DD.csv"`
- [x] Колонки: id, title, status, priority, tags, createdBy, createdAt
- [x] Коректне екранування (коми, лапки, переноси рядків), UTF-8 BOM
- [x] Фронт: кнопка «Export CSV» на сторінці списку (враховує поточні фільтри)

## Acceptance criteria
- CSV відкривається в Excel без «кракозябрів»
- Кількість рядків відповідає фільтру
- Ім'я файлу містить дату

## Playwright-тема
Download + перевірка вмісту файла.
