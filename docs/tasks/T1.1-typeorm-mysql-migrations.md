# T1.1 — TypeORM + MySQL + міграції

**Епік:** 1. База даних | **Залежності:** T0.2, T0.3 | **Оцінка:** M

## Мета
Підключити БД і керувати схемою через міграції.

## Що зробити
- [x] Встановити `@nestjs/typeorm`, `typeorm`, `mysql2`
- [x] Налаштувати `TypeOrmModule.forRootAsync` з `ConfigService`
- [x] `synchronize: false`, `migrationsRun: true`
- [x] Окремий `data-source.ts` для CLI
- [x] npm-скрипти: `migration:generate`, `migration:run`, `migration:revert`
- [x] Початкова (порожня) міграція для перевірки ланцюжка

## Acceptance criteria
- API підключається до MySQL у Docker
- `npm run migration:run` застосовує міграції, `revert` відкочує
- `/health` показує `db: up`

## Нотатки
Кодування таблиць: `utf8mb4`, collation `utf8mb4_unicode_ci`.
