# T4.4 — Сторінка друку тікета / Save as PDF

**Епік:** 4. Файли | **Залежності:** T3.4 | **Оцінка:** S

## Мета
Друк-френдлі версія тікета.

## Що зробити
- [ ] Роут `/tickets/:id/print` без навігації та кнопок
- [ ] `@media print` стилі (чорно-біле, розриви сторінок, шрифти)
- [ ] Кнопка «Print / Save as PDF» на сторінці тікета → `window.print()`
- [ ] На сторінці друку: заголовок, мета-дані, опис, коментарі, список вкладень

## Acceptance criteria
- У print-режимі немає меню та інтерактивних елементів
- Сторінка читабельна у форматі A4
- Контент відповідає тікету

## Playwright-тема
`page.pdf({ format: 'A4' })`, `page.emulateMedia({ media: 'print' })`.
