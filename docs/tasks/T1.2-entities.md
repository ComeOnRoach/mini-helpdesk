# T1.2 — Сутності: User, Ticket, Comment, Attachment

**Епік:** 1. База даних | **Залежності:** T1.1 | **Оцінка:** M

## Мета
Описати доменну модель і створити міграції.

## Схема
- **User:** id, email (unique), passwordHash, role (`user|agent`), createdAt
- **Ticket:** id, title, description, status (`open|in_progress|closed`), priority (`low|medium|high`), tags (JSON або окрема таблиця), createdBy → User, assignee → User (nullable), createdAt, updatedAt
- **Comment:** id, ticketId → Ticket, authorId → User, body, createdAt
- **Attachment:** id, ticketId → Ticket, filename, path, mime, size, createdAt
