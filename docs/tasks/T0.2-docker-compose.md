# T0.2 — docker-compose: MySQL + api + web

**Епік:** 0. Каркас і інфраструктура | **Залежності:** T0.1 | **Оцінка:** M

## Мета
Піднімати все середовище однією командою локально.

## Що зробити
- [x] Створити `docker-compose.yml` з сервісами `db` (MySQL 8), `api`, `web`
- [x] `db`: volume для даних, healthcheck (`mysqladmin ping`), порт 3306
- [x] `api`: `depends_on` з `condition: service_healthy`, порт 3000
- [x] `web`: порт 5173 (dev) або 8080 (nginx для prod-збірки)
- [x] Створити `.env.example` (DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME, JWT_SECRET, NODE_ENV)
- [x] Додати `docker-compose.override.yml` для dev (hot reload) — опційно

## Acceptance criteria
- `cp .env.example .env && docker compose up` піднімає всі 3 сервіси
- `db` позначається healthy, `api` стартує тільки після нього
- Дані MySQL зберігаються між перезапусками

## Нотатки
Dockerfile для api/web робляться окремо в T8.3; тут можна використати `node:20` + `command`.
