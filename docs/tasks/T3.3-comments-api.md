# T3.3 — Коментарі до тікета

**Епік:** 3. CRUD тікетів | **Залежності:** T3.2 | **Оцінка:** S

## Мета
Дати змогу вести обговорення в тікеті.

## Що зробити
- [ ] `POST /tickets/:id/comments` (body 1–2000 символів)
- [ ] `GET /tickets/:id/comments` (пагінація, старіші першими)
- [ ] Перевірка доступу до тікета
- [ ] Відповідь містить автора (id, email, role)

## Acceptance criteria
- Порожній коментар → 400
- Коментар до чужого тікета (для `user`) → 403/404
- Після створення повертається повний об'єкт коментаря
- Підготовлено подію для WebSocket (T5.1)
