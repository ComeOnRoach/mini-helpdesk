# T0.1 — Репозиторій, лінтери, workspaces

**Епік:** 0. Каркас і інфраструктура | **Залежності:** немає | **Оцінка:** S

## Мета
Створити базу репозиторію, щоб усі наступні задачі виконувались у єдиному стилі.

## Що зробити
- [ ] Створити репозиторій `helpdesk` на GitHub (public або private)
- [ ] Додати `.gitignore` (node_modules, dist, .env, uploads, coverage)
- [ ] Додати `.editorconfig` (utf-8, LF, 2 пробіли)
- [ ] Ініціалізувати npm workspaces: `apps/api`, `apps/web`
- [ ] Налаштувати ESLint + Prettier у корені (спільний конфіг)
- [ ] Додати скрипти в кореневий `package.json`: `lint`, `format`, `build`
- [ ] Налаштувати гілку `main` + feature-гілки (`feat/T0.1-...`)

## Acceptance criteria
- `npm install` у корені ставить залежності всіх workspaces
- `npm run lint` проходить без помилок на порожніх проєктах
- У репозиторії немає закомічених `node_modules` і `.env`
