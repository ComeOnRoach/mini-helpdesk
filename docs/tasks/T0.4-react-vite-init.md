# T0.4 — React + Vite фронтенд

**Епік:** 0. Каркас і інфраструктура | **Залежності:** T0.1 | **Оцінка:** S

## Мета
Мінімальний SPA-каркас із роутингом.

## Що зробити
- [ ] `npm create vite` у `apps/web` (React + TypeScript)
- [ ] Додати `react-router-dom`, налаштувати базові роути: `/`, `/login`, `/register`, `/tickets`, `/help`, `/contacts`
- [ ] Спільний `Layout` (хедер, навігація, контейнер)
- [ ] API-клієнт (`fetch`/`axios`) з `baseURL` з `VITE_API_URL`
- [ ] Сторінка-заглушка для кожного роуту

## Acceptance criteria
- `npm run dev` відкриває застосунок
- Навігація між заглушками працює без перезавантаження
- `npm run build` проходить

## Нотатки
UI-бібліотеку можна не підключати — простий CSS достатній.
