# T0.3 — NestJS проєкт, /health, Swagger

**Епік:** 0. Каркас і інфраструктура | **Залежності:** T0.1 | **Оцінка:** S

## Мета
Мати працюючий API-каркас із документацією.

## Що зробити
- [x] `nest new` у `apps/api` (TypeScript, strict mode)
- [x] Підключити `@nestjs/config` (читання `.env`, валідація змінних)
- [x] Додати `HealthModule`: `GET /health` → `{ status: "ok", db: "up|down" }` (`@nestjs/terminus`)
- [x] Підключити `@nestjs/swagger`, UI на `/docs`
- [x] Налаштувати глобальний префікс `/api` (health може бути без префікса)
- [x] Увімкнути CORS для адреси web

## Acceptance criteria
- `GET /health` повертає 200
- `/docs` відкривається та показує `/health`
- `npm run start:dev` працює з hot reload

## Нотатки
Порт 3000, конфіг через `ConfigService`, без жорстко прописаних значень.
