# T7.4 — Штучна затримка та нестабільність API

**Епік:** 7. Службові можливості | **Залежності:** T0.3 | **Оцінка:** S

## Мета
Дати змогу відпрацьовувати очікування, таймаути та retries.

## Що зробити
- [x] Env `SLOW_API_MS` — глобальний interceptor додає затримку до відповідей
- [x] Env `FLAKY_RATE` (0–1) — відсоток випадкових 500 на `GET /tickets` (за замовчуванням 0)
- [x] Заголовок `x-delay-ms` для разової затримки конкретного запиту (лише в test-режимі)
- [x] Фронт: коректні loading/error стани й кнопка «Повторити»
- [x] Додати в README та `.env.example`

## Acceptance criteria
- За замовчуванням затримки та помилок немає
- При `SLOW_API_MS=2000` відповіді затримуються
- Режими вмикаються лише через конфіг

## Playwright-тема
Auto-waiting, `retries`, `timeout`, flaky-тести.
