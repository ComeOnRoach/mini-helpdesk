# T8.1 — GitHub Actions: install → lint → build

**Епік:** 8. CI/CD | **Залежності:** T0.1, T0.3, T0.4 | **Оцінка:** S

## Мета
Базовий CI на кожен push і PR.

## Що зробити
- [ ] `.github/workflows/ci.yml`: тригери `push` (main) і `pull_request`
- [ ] Кроки: checkout → `actions/setup-node@v4` (Node 20, cache npm) → `npm ci` → `npm run lint` → `npm run build`
- [ ] Окремі job для api та web (matrix або паралельно)
- [ ] Бейдж статусу в README

## Acceptance criteria
- Pipeline зелений на чистій main
- Зламаний lint/build валить pipeline
- Кеш npm працює (другий запуск швидший)
