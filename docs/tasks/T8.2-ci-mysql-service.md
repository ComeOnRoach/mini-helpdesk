# T8.2 — CI: MySQL service, міграції, seed

**Епік:** 8. CI/CD | **Залежності:** T8.1, T1.3 | **Оцінка:** M

## Мета
У CI застосунок має стартувати з реальною БД.

## Що зробити
- [x] У job додати `services: mysql` (image `mysql:8`, env, health-cmd, порт 3306)
- [x] Передати env для API (DB_HOST=127.0.0.1 тощо, `NODE_ENV=test`)
- [x] Кроки: `migration:run` → `seed` → запуск API у фоні → очікування `/health` (curl з retry)
- [x] Зібрати та запустити web (preview) у фоні
- [x] Логи API як артефакт при падінні

## Acceptance criteria
- У CI `/health` повертає `db: up`
- Seed створює відомі дані
- Job падає, якщо API не стартував за таймаут
