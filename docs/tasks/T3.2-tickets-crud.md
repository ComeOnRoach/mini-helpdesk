# T3.2 — CRUD тікета

**Епік:** 3. CRUD тікетів | **Залежності:** T3.1 | **Оцінка:** M

## Мета
Створення, читання, оновлення, видалення тікетів.

## Що зробити
- [ ] `POST /tickets` (title 3–120 символів, description, priority, tags)
- [ ] `GET /tickets/:id` (з коментарями та вкладеннями)
- [ ] `PATCH /tickets/:id` (змінити title/description/priority/tags; status та assignee — лише agent)
- [ ] `DELETE /tickets/:id` (лише agent або автор у статусі open)
- [ ] Перевірки прав і 404 для неіснуючих

## Acceptance criteria
- Створений тікет має `status=open`, `createdBy` = поточний user
- `user` не може змінити status/assignee → 403
- Неіснуючий id → 404
- Усі DTO валідуються
