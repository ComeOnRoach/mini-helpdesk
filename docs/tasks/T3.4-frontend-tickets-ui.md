# T3.4 — Фронт: список, форма, сторінка тікета

**Епік:** 3. CRUD тікетів | **Залежності:** T2.4, T3.1, T3.2, T3.3 | **Оцінка:** L

## Мета
Основний UI роботи з тікетами.

## Що зробити
- [ ] `/tickets`: таблиця, фільтри (status, priority, tag), поле пошуку, пагінація
- [ ] Стани: loading, empty, error
- [ ] `/tickets/new` та `/tickets/:id/edit`: форма з валідацією
- [ ] `/tickets/:id`: деталі, коментарі, форма додавання коментаря, кнопки Edit/Delete
- [ ] Підтвердження видалення (модальне вікно)
- [ ] Зміна статусу (select) для agent
- [ ] Toast-повідомлення про успіх/помилку

## Acceptance criteria
- Усі CRUD-операції доступні з UI
- Фільтри та сторінка зберігаються в query-string (`?status=open&page=2`)
- Кнопки/поля приховані або заблоковані за роллю

## Playwright-тема
POM (TicketsPage, TicketDetailsPage, TicketForm), таблиці, модальні вікна.
