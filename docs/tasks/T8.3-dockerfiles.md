# T8.3 — Dockerfile для api і web

**Епік:** 8. CI/CD | **Залежності:** T0.2 | **Оцінка:** M

## Мета
Відтворювані production-образи.

## Що зробити
- [ ] `apps/api/Dockerfile`: multi-stage (build → runtime), non-root user, `npm ci --omit=dev`
- [ ] `apps/web/Dockerfile`: build Vite → nginx зі `try_files` для SPA, службовими файлами та CSP
- [ ] `.dockerignore` для обох
- [ ] Оновити `docker-compose.yml` на використання образів
- [ ] CI-job: `docker build` для обох образів

## Acceptance criteria
- Образи збираються локально й у CI
- Розмір образу api розумний (< 300 MB)
- Контейнер не працює від root
