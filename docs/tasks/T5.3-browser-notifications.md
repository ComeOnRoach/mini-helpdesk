# T5.3 — Browser notifications (permissions)

**Епік:** 5. Real-time | **Залежності:** T5.2 | **Оцінка:** S

## Мета
Запит дозволу на системні сповіщення.

## Що зробити
- [ ] Кнопка «Увімкнути сповіщення» в налаштуваннях/хедері
- [ ] `Notification.requestPermission()` і відображення статусу (granted/denied/default)
- [ ] При події `comment.added`, коли вкладка неактивна, показати `new Notification(...)`
- [ ] Підказка, якщо дозвіл заблоковано користувачем

## Acceptance criteria
- Статус дозволу відображається правильно
- Без дозволу сповіщення не показуються й нічого не падає
- Клік по сповіщенню відкриває тікет

## Playwright-тема
`context.grantPermissions(['notifications'])`.
