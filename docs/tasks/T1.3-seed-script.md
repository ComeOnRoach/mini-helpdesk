# T1.3 — Seed-скрипт

**Епік:** 1. База даних | **Залежності:** T1.2 | **Оцінка:** S

## Мета
Мати детерміновані стартові дані для ручної перевірки та майбутніх тестів.

## Що зробити
- [ ] Скрипт `npm run seed` (повторюваний, ідемпотентний)
- [ ] 2 користувачі: `user@example.com` (role user), `agent@example.com` (role agent), відомі паролі
- [ ] 10–15 тікетів із різними статусами, пріоритетами, тегами
- [ ] Кілька коментарів до частини тікетів
- [ ] Функція seed винесена в сервіс, щоб перевикористати в T7.3

## Acceptance criteria
- Після `seed` у БД є 2 користувачі та 10–15 тікетів
- Повторний запуск не створює дублікатів
- Логін під обома акаунтами можливий (після T2.1)

## Нотатки
Дані мають бути стабільними (без `Math.random`) — це важливо для автотестів.
