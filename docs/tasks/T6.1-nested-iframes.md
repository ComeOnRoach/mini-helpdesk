# T6.1 — iframe і вкладений iframe

**Епік:** 6. Складні UI-сценарії | **Залежності:** T0.4 | **Оцінка:** M

## Мета
Сторінка з віджетом у iframe та другим iframe всередині.

## Що зробити
- [x] Сторінка `/help` із `<iframe id="faq-frame" title="FAQ">`
- [x] Сторінка `/widgets/faq.html` (статика): список питань-відповідей (accordion), пошук
- [x] У ній ще один `<iframe id="feedback-frame">` → `/widgets/feedback.html` із формою «Був корисним?» (Так/Ні + коментар + Submit)
- [x] Після Submit — повідомлення «Дякуємо» всередині вкладеного iframe
- [x] Стабільні `id`/`data-testid` усередині фреймів

## Acceptance criteria
- Усі три рівні (сторінка, iframe, вкладений iframe) відображаються
- Форма у вкладеному iframe працює незалежно
- Фрейми того ж origin

## Playwright-тема
`frameLocator('#faq-frame').frameLocator('#feedback-frame')`.
