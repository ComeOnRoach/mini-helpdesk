# T6.1 — iframe і вкладений iframe

**Епік:** 6. Складні UI-сценарії | **Залежності:** T0.4 | **Оцінка:** M

## Мета
Сторінка з віджетом у iframe та другим iframe всередині.

## Що зробити
- [ ] Сторінка `/help` із `<iframe id="faq-frame" title="FAQ">`
- [ ] Сторінка `/widgets/faq.html` (статика): список питань-відповідей (accordion), пошук
- [ ] У ній ще один `<iframe id="feedback-frame">` → `/widgets/feedback.html` із формою «Був корисним?» (Так/Ні + коментар + Submit)
- [ ] Після Submit — повідомлення «Дякуємо» всередині вкладеного iframe
- [ ] Стабільні `id`/`data-testid` усередині фреймів

## Acceptance criteria
- Усі три рівні (сторінка, iframe, вкладений iframe) відображаються
- Форма у вкладеному iframe працює незалежно
- Фрейми того ж origin

## Playwright-тема
`frameLocator('#faq-frame').frameLocator('#feedback-frame')`.
