# T4.2 — Скачування вкладень

**Епік:** 4. Файли | **Залежності:** T4.1 | **Оцінка:** S

## Мета
Дати змогу завантажити прикріплений файл.

## Що зробити
- [x] `GET /attachments/:id/download` з `Content-Disposition: attachment; filename="..."`
- [x] Перевірка прав доступу до тікета
- [x] Правильний `Content-Type`
- [x] Фронт: посилання/кнопка «Download» біля кожного вкладення

## Acceptance criteria
- Браузер завантажує файл з оригінальним ім'ям
- Чужий файл (для `user`) → 403/404
- Вміст завантаженого файла ідентичний завантаженому

## Playwright-тема
`page.waitForEvent('download')`, `download.saveAs()`, `suggestedFilename()`.
