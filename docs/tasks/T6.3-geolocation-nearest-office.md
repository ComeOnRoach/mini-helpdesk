# T6.3 — Геолокація: найближчий офіс

**Епік:** 6. Складні UI-сценарії | **Залежності:** T0.4 | **Оцінка:** M

## Мета
Сторінка, що використовує `navigator.geolocation`.

## Що зробити
- [x] Сторінка `/contacts` зі списком 3 офісів (назва, адреса, координати) — напр. Lisbon, Kyiv, Berlin
- [x] Кнопка «Найближчий офіс» → `getCurrentPosition`
- [x] Розрахунок відстані (формула Haversine), виділення найближчого та показ відстані в км
- [x] Обробка помилок: дозвіл відхилено, недоступно, таймаут — окремі повідомлення
- [x] Стан loading

## Acceptance criteria
- За відомих координат завжди визначається один і той самий найближчий офіс
- При відмові в дозволі показується зрозуміле повідомлення
- Відстань округлена до 1 знака

## Playwright-тема
`context.grantPermissions(['geolocation'])`, `context.setGeolocation(...)`.
