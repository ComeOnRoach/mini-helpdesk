# T5.1 — WebSocket gateway

**Епік:** 5. Real-time | **Залежності:** T3.2, T3.3 | **Оцінка:** M

## Мета
Сповіщати клієнтів про зміни в реальному часі.

## Що зробити
- [ ] `@nestjs/websockets` + Socket.IO (або `ws`)
- [ ] Автентифікація підключення за JWT (handshake)
- [ ] Події: `ticket.created`, `ticket.updated`, `comment.added`
- [ ] Кімнати: `ticket:<id>` для підписників тікета, `agents` для всіх агентів
- [ ] Емітити події з сервісів тікетів і коментарів
- [ ] Документувати формат payload у README

## Acceptance criteria
- Неавторизоване підключення відхиляється
- Новий коментар доходить усім, хто підписаний на тікет
- `user` не отримує події чужих тікетів

## Playwright-тема
`page.on('websocket')`, перевірка фреймів.
