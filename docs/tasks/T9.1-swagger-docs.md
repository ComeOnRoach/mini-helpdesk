# T9.1 — Swagger: повний опис ендпоінтів

**Епік:** 9. Фіналізація | **Залежності:** усі API-задачі (Е2–Е7) | **Оцінка:** M

## Мета
Повна, актуальна API-документація з прикладами.

## Що зробити
- [ ] Для кожного контролера: `@ApiTags`, `@ApiOperation`, `@ApiResponse` (успіх + типові помилки 400/401/403/404)
- [ ] DTO з `@ApiProperty` (опис, приклад, enum)
- [ ] Схема авторизації `@ApiBearerAuth` + кнопка Authorize у Swagger UI
- [ ] Приклади запитів/відповідей для auth, tickets, comments, attachments, stats
- [ ] Для multipart (attachments) — `@ApiConsumes('multipart/form-data')`
- [ ] Тестові ендпоінти (`/test/*`) приховані в production

## Acceptance criteria
- Усі публічні ендпоінти присутні в `/docs`
- Через Swagger UI можна залогінитись і виконати CRUD тікета
- Формат помилок збігається з T2.3
