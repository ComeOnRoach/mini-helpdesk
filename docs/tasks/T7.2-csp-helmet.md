# T7.2 — CSP через helmet

**Епік:** 7. Службові можливості | **Залежності:** T0.3 | **Оцінка:** M

## Мета
Налаштована Content Security Policy.

## Що зробити
- [ ] Підключити `helmet` в API
- [ ] Для web: CSP-заголовок через nginx/Vite preview або meta-тег
- [ ] Політика: `default-src 'self'`; `connect-src 'self' <API> ws://...`; `img-src 'self' data:`; `frame-src 'self'` (для iframe з T6.1)
- [ ] Керування через env: `CSP_ENABLED`, `CSP_REPORT_ONLY`
- [ ] Ендпоінт `POST /csp-report` (логування порушень)

## Acceptance criteria
- При `CSP_ENABLED=true` заголовок присутній у відповідях
- Застосунок працює під CSP без помилок у консолі
- Інлайн-скрипт стороннього походження блокується

## Playwright-тема
`bypassCSP`, `context.addInitScript`, перевірка заголовків відповіді.
