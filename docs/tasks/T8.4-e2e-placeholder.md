# T8.4 — Місце під Playwright (поки порожнє)

**Епік:** 8. CI/CD | **Залежності:** T8.2 | **Оцінка:** S

## Мета
Підготувати структуру та точку розширення для майбутніх e2e-тестів, не додаючи самих тестів.

## Що зробити
- [ ] Створити папку `e2e/` з `README.md` (призначення, плани)
- [ ] У `e2e/README.md` — таблиця «Фіча → тема Playwright» (посилання на задачі)
- [ ] У `ci.yml` додати закоментований job `e2e` (checkout → install → `npx playwright install --with-deps` → `npx playwright test` → upload report)
- [ ] Узгодити змінні: `BASE_URL`, `API_URL`, `TEST_API_KEY`

## Acceptance criteria
- Папка `e2e/` є в репозиторії, CI не змінює результату
- Розкоментувавши job, можна запустити тести без додаткових змін у застосунку

## Нотатки
Самі тести — окремий етап, поза цим проєктом.
