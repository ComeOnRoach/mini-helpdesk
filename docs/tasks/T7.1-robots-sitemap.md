# T7.1 — robots.txt і sitemap.xml

**Епік:** 7. Службові можливості | **Залежності:** T0.4 | **Оцінка:** S

## Мета
Статичні службові файли, доступні з web.

## Що зробити
- [ ] `apps/web/public/robots.txt`: `User-agent: *`, `Disallow: /admin`, `Disallow: /tickets`, `Sitemap: <URL>/sitemap.xml`
- [ ] `apps/web/public/sitemap.xml`: публічні сторінки (`/`, `/login`, `/register`, `/help`, `/contacts`)
- [ ] Перевірити віддачу з правильним `Content-Type`
- [ ] Згадати у README

## Acceptance criteria
- `GET /robots.txt` → 200, `text/plain`
- `GET /sitemap.xml` → 200, валідний XML
- Приватні сторінки не потрапляють у sitemap

## Playwright-тема
Запит через `request`/`page.goto`, `context.route('**/robots.txt', ...)` для підміни.
