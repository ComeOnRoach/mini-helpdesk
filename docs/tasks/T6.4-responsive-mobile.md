# T6.4 — Адаптивна (мобільна) верстка

**Епік:** 6. Складні UI-сценарії | **Залежності:** T3.4 | **Оцінка:** M

## Мета
Коректна робота на вузьких екранах.

## Що зробити
- [ ] `<meta name="viewport">`
- [ ] Брейкпоінт ≤ 768px: навігація перетворюється на бургер-меню
- [ ] Таблиця тікетів → картки на мобільному
- [ ] Форми та модальні вікна адаптовані
- [ ] Touch-friendly розміри кнопок (≥ 44px)

## Acceptance criteria
- Бургер-меню відкривається/закривається, посилання працюють
- На 375px немає горизонтального скролу
- Десктопна версія не змінилась

## Playwright-тема
`devices['iPhone 13']`, перевірка видимості бургера, `isMobile`, touch.
