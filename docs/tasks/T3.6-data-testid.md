# T3.6 — data-testid на ключових елементах

**Епік:** 3. CRUD тікетів | **Залежності:** T3.4 | **Оцінка:** S

## Мета
Стабільні локатори для майбутніх автотестів.

## Що зробити
- [ ] Узгодити конвенцію: `kebab-case`, `<сторінка>-<елемент>` (наприклад `login-email`, `ticket-row`, `ticket-create-submit`)
- [ ] Додати до форм (inputs, submit), кнопок, рядків таблиці, модальних вікон, toast, навігації
- [ ] Для списків: `data-testid="ticket-row"` + `data-ticket-id`
- [ ] Описати конвенцію в README
- [ ] Лінт-правило або чекліст у PR

## Acceptance criteria
- Усі інтерактивні елементи основних сторінок мають testid
- Конвенція задокументована
- Немає дублікатів testid на одній сторінці (крім рядків списків)

## Нотатки
У Playwright можна налаштувати `testIdAttribute` у конфігу.
