# T6.6 — Перемикач теми light/dark

**Епік:** 6. Складні UI-сценарії | **Залежності:** T0.4 | **Оцінка:** S

## Мета
Збереження налаштування UI в localStorage.

## Що зробити
- [ ] Кнопка-перемикач у хедері
- [ ] CSS-змінні для двох тем, клас/атрибут `data-theme` на `<html>`
- [ ] Збереження в `localStorage` (ключ `theme`)
- [ ] Початкове значення: збережене або `prefers-color-scheme`
- [ ] Без «блимання» теми при завантаженні

## Acceptance criteria
- Вибір зберігається після reload
- Тема застосовується до всіх сторінок
- Перемикач має `aria-label` і `data-testid`

## Playwright-тема
`localStorage.setItem`, `colorScheme` у контексті, перевірка CSS.
