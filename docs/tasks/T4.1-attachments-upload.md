# T4.1 — Завантаження вкладень

**Епік:** 4. Файли | **Залежності:** T3.2 | **Оцінка:** M

## Мета
Прикріплення файлів до тікета.

## Що зробити
- [ ] `POST /tickets/:id/attachments` (multipart, поле `file`), `multer`
- [ ] Ліміт розміру (напр. 5 MB) і дозволені типи: png, jpg, pdf, txt, csv
- [ ] Зберігання у `uploads/` з унікальним іменем; запис у таблицю `Attachment`
- [ ] Volume для `uploads/` у docker-compose
- [ ] Фронт: `<input type="file">`, прогрес/список файлів, видалення вкладення
- [ ] Зрозумілі помилки (завеликий файл → 413, тип → 415/400)

## Acceptance criteria
- Допустимий файл зберігається й відображається у тікеті
- Завеликий або заборонений тип відхиляється з повідомленням
- Файли переживають перезапуск контейнера

## Playwright-тема
`locator.setInputFiles()`, негативні сценарії завантаження.
