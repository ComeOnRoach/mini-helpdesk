# T6.2 — Pop-up «Поділитися»

**Епік:** 6. Складні UI-сценарії | **Залежності:** T3.4 | **Оцінка:** S

## Мета
Кнопка, що відкриває нове вікно.

## Що зробити
- [ ] Кнопка «Поділитися» на сторінці тікета → `window.open('/share/:id', 'share', 'width=500,height=600')`
- [ ] Сторінка `/share/:id`: назва тікета, посилання, кнопка «Copy link», «Close»
- [ ] «Copy link» → `navigator.clipboard.writeText` + повідомлення «Скопійовано»
- [ ] «Close» → `window.close()`

## Acceptance criteria
- Відкривається окреме вікно з правильним тікетом
- Основне вікно залишається активним
- Копіювання показує підтвердження

## Playwright-тема
`context.waitForEvent('page')` / `page.waitForEvent('popup')`.
